## S1. 설계 원칙 (문제정의 → 강제 제약)

1. **문자열 편집 금지** — 모든 `.twb` 변경은 파싱된 트리 조작 → 재직렬화. 문자열 치환 불허.
2. **2계층 검증 게이트** — 모든 산출물은 (A)XSD 구문 + (B)시맨틱 검증 통과해야 반환. 하나라도 실패 시 반환 금지.
3. **참조 자동 정합** — 편집이 참조를 깨면(rename/삭제) 의존 참조를 함께 갱신하거나, 못 하면 편집 거부.
4. **빠른 오프라인 우선, E2E는 최종 게이트** — per-edit는 정적검증만. E2E(앱실행·렌더)는 선택적 최종 1회.
5. **결정론** — 같은 입력 → 같은 출력. 무인 자동화 가능.

## S2. 기능 요구사항 (능력 단위, 구현중립)

- **C1 안전 I/O** — `.twbx` unpack/pack (`.hyper` 바이너리 무손실 보존), `.twb` 파싱/직렬화.
- **C2 인스펙터** — 구조 모델 추출: datasources·fields·calc·sheets·dashboards·참조관계. (편집/쿼리 컨텍스트 제공)
- **C3 검증기 (2계층, 핵심 산출물)**
  - **L-A 구문**: 버전 매칭 공식 XSD 검증 (`twb_YYYY.R.0.xsd`).
  - **L-B 시맨틱**: ①calc 함수 화이트리스트 ②calc 필드참조 해소 ③named-content 참조무결성 ④메타↔hyper 스키마 대조 ⑤connection 필수속성.
  - 출력 = 구조화된 findings(severity·위치·원인·수정제안).
- **C4 안전 편집기** — 트리 연산: 필드 추가/수정, calc 편집, connection 변경, 색·레이아웃. 각 연산은 의존참조 자동갱신 + dangling 유발 시 거부.
- **C5 데이터 쿼리** — embedded `.hyper` 위 SQL/집계 (쿼리·분석 작업).
- **C6 E2E 게이트(선택)** — Tableau 실행→렌더→스크린샷으로 render 계층 최종확인. per-edit 아님.
- **C7 저작(build)** — 템플릿 + C4 연산으로 맨바닥 `.twb` 생성 (2차 범위).

## S3. 입출력 계약 (작업유형별)

- **편집(fix)**: `입력` = 대상 `.twbx/.twb` + 편집의도(자연어→구조화 연산). `출력` = 검증통과 산출파일 + 변경요약 + findings리포트. `불변식` = C3 2계층 통과 or 실패사유 반환(원본 무손상).
- **쿼리(query)**: `입력` = 대상파일 + 질의. `출력` = 결과셋 + 사용스키마. `불변식` = 파일 비변경(read-only).
- **저작(build)**: `입력` = 데이터소스 + 명세(시트/차트/calc). `출력` = 검증통과 신규 `.twbx`. `불변식` = C3 통과.

## S4. 검증 기준 (Acceptance Criteria)

- **AC1 무에러**: 골든셋(정상+고장 쌍)에서 산출물 100% Tableau 로드 성공.
- **AC2 시맨틱 검출율**: L-B가 로드-실패 유발 케이스(calc·참조·메타↔hyper)를 목표율 이상 검출 (목표 수치는 골든셋 확정 후 고정).
- **AC3 무거짓통과**: C3 통과했는데 로드 실패 = 치명결함(0 목표). 발견 시 해당 유형 L-B 규칙 추가.
- **AC4 참조무결성**: 의도적 dangling 주입 → C4가 거부 또는 자동수정.
- **AC5 속도**: per-edit 검증이 E2E 대비 유의미하게 빠름 (목표 배수는 벤치 후 고정).
- **AC6 read-only 안전**: 쿼리 작업이 원본 바이트 비변경.

## S5. 비기능 요구사항

- **속도**: 정적검증 per-edit 목표 수초 내. E2E는 최종 1회로 격리.
- **버전대응**: TWB version ↔ XSD 자동 매칭(`26.1`→`twb_2026.1.0.xsd`), 미지원 버전 명시 경고.
- **범위한계 명시**: live DB connection·`processContents=skip`·render 계층은 "오프라인 미검증" 경고 표기(조용히 통과 금지).
- **원본 보존**: 편집 실패 시 원본 무손상, 항상 재현 가능.

## S6. 스펙 단계 미결 (설계에서 결정)

- 함수 화이트리스트 소스·유지방식, calc 파서 자체구현 여부.
- 골든셋 구성(고장 유형별 최소 케이스 수), AC2/AC5 목표 수치.
- 패키징 형태(MCP 코어 + Skill + Plugin) 최종확정 — 호스트 결정과 연동.
- C7 저작 템플릿 범위.
