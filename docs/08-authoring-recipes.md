## 1. 문제 (한 문장)

> **AI가 `.twb/.twbx` XML을 쓸 때 "정답 형태"를 알려주는 문서가 세상에 없다.**
> Tableau가 UI 조작 A를 XML로 어떻게 적는지를 실측해 조작별 레시피로 만들고,
> AI가 작업 A를 요청받으면 레시피 A를 찾아 **정본 형태로** 쓰게 한다.

## 2. 왜 검증기만으로 부족한가

twb-lint(01 v2.0)는 **사후 판정**이다 — 틀림을 잡지만 맞는 형태를 제시하지 못한다.

- 저작 2차 실측(05 F5-g)에서 층 2~4 검출이 1/8이었다. 규칙을 늘려 4/8이 됐지만,
  **애초에 정본 형태로 썼다면 그 결함들은 발생하지 않았다.**
- 현재 AI 저작의 정답 출처는 "기존 파일에서 유추"뿐이다. 유추는 파일마다 다시 하고,
  세션이 끝나면 사라진다. 지식이 축적되지 않는다.
- Tableau 공식 XSD는 구문(A)만 커버하고, 시맨틱(B)은 명시적 非커버다(01 A.4).
  "무엇을 쓰면 되는가"는 어느 공식 문서에도 없다.

**검증(사후)과 레시피(사전)는 같은 목적의 두 날이다** — AI가 Tableau 파일을 안 깨고 다루게 한다.

코퍼스가 이미 낸 저작 지식(레시피에 들어갈 종류의 사실):

- **정규화 실측** (227b603) — 손으로 쓴 XML을 Tableau가 열고 고친 것은 3종뿐
  (column-instance 순서 · window 블록 정렬 · Phone `fixed-size` 재계산). 나머지는 전부 수용.
  → 미리 정본 형태로 쓰면 재저장 diff가 신호만 남는다
- **순서 제약** (6154648) — `<action>`은 `<edit-parameter-action>`보다 앞. 어기면 XSD 거부
- **unique 제약** (8df7c57) — `<window>`의 `<simple-id uuid>`는 XSD unique 대상. 복사 시 새 uuid 필수
- **제외 기록 방식** (b13bc5a, b67ed82) — 동작의 대상·원본 시트는 포함이 아니라 **제외**로 기록.
  새 시트를 만들면 기존 동작의 exclude 목록에 자동으로 안 들어간다 = 의도치 않게 동작이 걸린다
- **3곳 동시 규칙** (b63e1b1) — 워크시트 생성·개명은 `<worksheet>`·`<window>`·`<thumbnail>` 동반
- **개명은 참조를 안 깨진다** (e6a02cc) — caption만 바뀌고 내부 `name`은 유지

## 4. 해결 방향

**조작 1개 = 레시피 문서 1개.** 흐름:

```
작업 요청 A → 레시피 A 조회 → 정본 형태로 XML 작성 → twb-lint → (최종 1회) Tableau 재저장 확인
```

레시피 형식(안): UI 경로 · before/after XML 조각 · 불변 조건(순서·unique·동반 변경) ·
근거 커밋 sha · `확인/추정` 등급. 산문 금지 — 기계가 따라할 수 있는 단위.

위치: **이 저장소** (`docs/recipes/`, 예정). 근거 커밋은 MA_008 sha로 참조만 한다 —
코퍼스 저장소는 사내 재무 데이터라 저장소 간 분리를 유지한다.

## 5. 성공 기준

- **레시피만 보고 재현 가능** — 해당 조작을 코퍼스 없이 레시피만으로 XML에 재현했을 때
  twb-lint ERROR 0
- **정규화 0** — 그 파일을 Tableau가 열고 재저장한 diff에 노이즈만 남는다
  (= Tableau가 정본으로 인정했다). 판정법은 신호노이즈.md 3분류
- **빨간 느낌표 0** — 01 §5와 동일. 레시피는 이 기준을 앞당겨 달성하는 수단이다
- **근거 없는 서술 0** — 모든 레시피 행에 근거 커밋 sha 또는 `확인/추정` 등급이 붙는다.
  관찰 없는 추측을 레시피로 적지 않는다

## 6. 비-목표

- **전 UI 기능 망라** — 커버리지 단위는 관찰된 기능이다. 코퍼스에 없는 기능은
  레시피가 없는 것이 정상이고, 없음을 아는 것이 거짓 레시피보다 낫다
- **UI 자동화·매크로** — 레시피는 XML 저작 지식이지 Tableau 조작 도구가 아니다
- **레이아웃 미학** — 01 §6과 동일. 오류 없음까지만
- **범용 버전 커버** — 2026.1 고정 (02 S7)

## 7. 열린 질문

- **미관찰 기능의 조달 절차** — 레시피 전량 변환 후 Tableau 기능 전체 리스트를 만들어
  미관찰 항목을 표시한다. 미관찰분은 소유자가 관찰 모드로 조작해 코퍼스에 공급한다
  (2026-08-06 합의). 당장 보이는 구멍: 집합(`<group>`)·집합 동작 — T3 표면인데 관찰 0건
- **`?` 표시 신호** — 다중 동작 저장에서 대응이 불확실한 델타. 레시피로 승격하려면
  관찰 모드 재관찰이 필요하다. 몇 건인지 인벤토리에서 센다
- **레시피 진부화** — Tableau 업그레이드 시 재검증 절차. 지금은 2026.1 고정이라 유예
