NULL인 셀에 글자를 붙이는 방법이다. Measure Names/Values 그리드는 **숫자 측정값만** 올릴 수 있어서
계산 필드가 `"N/A"` 같은 글자를 돌려줄 수 없다 — 이 서식이 유일한 길이다.

## XML 변경 — 어디에 무엇을

워크시트 `style-rule[@element='table']` 안, **필드 한정** `<format>` 2줄. (셀 서식 `text-format`이 사는
`element='cell'`이 **아니다** — 자리가 다르다.)

```xml
<style-rule element='table'>
  <format attr='band-size' scope='rows' value='1' />
  <format attr='alternate-text' field='[federated.…].[usr:Calculation_1567122779770883:qk]' value='N/A' />
  <format attr='display-alternate-text' field='[federated.…].[usr:Calculation_1567122779770883:qk]' value='true' />
</style-rule>
```

| 속성 | 값 규칙 |
|---|---|
| `alternate-text` | NULL 셀에 보일 글자 |
| `display-alternate-text` | `true` — 글자를 **켜는 스위치**. 두 줄이 한 쌍이다 |
| `@field` | `[<ds>].[usr:<필드 name>:qk]` — 셀 서식(`text-format`)·Measure Values 인스턴스와 같은 표기 |

- 필드마다 따로 지정한다. 지정한 필드(컬럼)만 적용된다.
- 같은 필드의 숫자 서식은 그대로 `element='cell'`의 `text-format`이다 (`n#,##0;-#,##0` 등). 둘은 독립이다.

## 숫자 서식으로는 못 하는 것 — 부정 결과 (2026-10-23 소유자 스크린샷)

`text-format`의 **조건 구간은 안 먹는다.** 이렇게 썼더니

```xml
<format attr='text-format' field='…' value='n[&gt;=9999999995]&quot;NA&quot;;[&gt;=9999999990]&quot;DIV&quot;;#,##0' />
```

Tableau가 `[>=…]` 조건을 **무시하고 `양수;음수;0` 구간으로 읽었다.** 정상 양수 값이 전부 `NA`로,
정상 음수 값이 전부 빨간 `DIV`로 그려졌다. → 센티널 숫자 + 조건 서식으로 특수 상태를 글자로 바꾸는 방식은 **쓰지 않는다.**

쓸 수 있는 구간은 `양수;음수;0` 셋뿐이다. 그래서 "NULL=N/A, 0으로 나눔=DIV"의 현실적 구성은
- NULL → 이 레시피의 `alternate-text`
- 분모 0 → 계산식이 정확히 `0`을 돌려주고, 서식의 **세 번째(0) 구간**에 글자 — 접두어는 **`*`** (아래)
- 진짜 0인 값은 `0.0000001`처럼 0이 아닌 값으로 돌려 반올림 표시한다

### 0 구간 글자 — 접두어는 `n`이 아니라 `*` (2026-10-27 소유자 확인)

```xml
<format attr='text-format' field='…' value='*#,##0;-#,##0;&quot;DIV&quot;' />
```

| 접두어 | 셀에 `DIV`가 그려지나 | 서식 창(사용자 지정)에 보이나 |
|---|---|---|
| `n#,##0;-#,##0;"DIV"` | 그려진다 | **안 보인다** — 사용자가 열어 보면 서식이 없는 것처럼 보인다 |
| `*#,##0;-#,##0;"DIV"` | 그려진다 | 보인다 |

- UI 경로: 측정값 우클릭 > 서식 > 패널 > 기본값 > 숫자 > **사용자 지정**에 `#,##0;-#,##0;"DIV"` 입력 → 저장하면 `*` 접두어로 직렬화된다.
- 근거: 소유자가 UI로 입력한 저장값 관찰 + AI 저작본 78개 서식을 `n`→`*`로 일괄 변환 후 `twb_validate` 통과.
- 글자 구간이 **없는** 평범한 숫자 서식(`n#,##0;-#,##0`)은 이 관찰의 범위 밖이다 — 그대로 둔다.

## 불변 조건

1. `alternate-text`와 `display-alternate-text`는 **짝**이다 (샘플에서 둘이 함께 생겼다)
