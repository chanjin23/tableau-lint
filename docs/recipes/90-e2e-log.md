**twb-lint는 두 결함 모두 `passed=true`로 통과시켰다.** 층 1은 이번 반복에 막았고,
크래시 쪽은 규칙이 없다.

### 그래서 관찰을 뒤집었다 — 통제 diff 3단

손저작을 고치는 대신 **소유자가 Tableau로 3단계를 저장**했다. 한 단계가 한 조작이라
diff가 그대로 레시피가 된다.

| 파일 | 조작 | 산출 레시피 |
|---|---|---|
| `관찰_A_빈워크북.twb` | 새 통합 문서 → 저장 | [20](./20-empty-workbook.md) 워크북 골격 · **매니페스트 최소 4항목** |
| `관찰_B_CSV연결만.twb` | CSV 연결만 | [21](./21-datasource-csv.md) 데이터 원본 · **매니페스트 +3항목** |
| `관찰_00_base.twb` | 시트 2개 뷰 구성 | [22](./22-first-field-placement.md) 첫 배치 동반 변경 6곳 |

세 파일 전부 `twb_validate` **passed · findings 0**.

### 이 반복에서 얻은 것

1. **매니페스트에 최소 집합이 있다** — 빈 워크북 4항목. 기능을 쓸 때마다
   알파벳 순으로 늘어난다. 실파일의 22항목을 복사하는 것은 과선언이다
2. **`<viewpoint><highlight>`는 Tableau가 자동 생성**한다 — 뷰에 올린 차원이
   자동으로 들어간다. MA_002 감사에서 본 "대시보드 하이라이트 목록의 dangling"이
   왜 생기는지가 여기서 설명된다 (필드를 지워도 이 목록은 자동으로 안 준다)
3. **관찰은 통제 diff가 압도적으로 낫다** — 실파일 106개 정적 상관으로도
   `simple-id` 게이트를 못 갈랐는데, 변형 2개를 열어 보니 한 번에 갈렸다

## E2E-3 (2026-08-10) — 통제 관찰 11건, **전건 성공**

소유자가 지시서대로 한 조작씩 저장했다. **한 저장 = 한 조작**을 지켰기 때문에
diff가 그대로 레시피가 됐다.

| 저장본 | 조작 | 산출 |
|---|---|---|
| `관찰_00_base` | 시트 2개 뷰 구성 | 레시피 22 교차검증 |
| `관찰_01`~`05` | 필터 5종 | 레시피 12 대폭 확장 |
| `관찰_06`~`09` | 집합 4종 | **레시피 23 신규** |
| `관찰_10` | 도구 설명 뷰 | **레시피 24 신규** |
| `관찰_11` | 툴팁 크기 | **미수행** — UI 경로 못 찾음 (아래) |

**12개 전부 `twb_validate` passed · findings 0.**

### 미검증 항목 하나가 여기서 풀렸다

0단계 출발 파일(`관찰_실험_V2_columns없음.twb`)은 `<relation>`의 `<columns>`가
일부러 빠진 결함본이었다. **Tableau가 저장하면서 되채웠다** — 열 5개가 원래 순서·
속성 그대로 복원됐다. `<columns>` 누락은 **정규화로 흡수되는 무해 항목**으로 확정.
규칙에 넣지 않은 판단(R25 V2)이 두 번째 근거를 얻었다.

### 얻은 것

1. **집합 배치 표본 0의 벽이 뚫렸다** — `io:` 한정자(`derivation='InOut'`,
   `[io:<집합>:nk]`)가 사용자 집합을 뷰에 올리는 유일한 표기다. R20-b가 폐기됐던
   이유(배치 표본 0)가 해소됐다
2. **도구 설명 뷰는 `<action>`을 만들지 않는다** — 숨은 집합 + `user:ui-action-filter`
   속성으로만 배선된다. 매니페스트에 `VizInTooltipHideWorksheet`가 붙는다
3. **필터는 `<slices>`와 짝이다** — `<filter>`만 쓰면 반쪽이다
4. 데이터 원본 필터는 자리·표기가 워크시트 필터와 **전부 다르다**
   (`<datasource>` 안 · 1단 원시 이름 · `<slices>` 없음)

### 남은 것

- `관찰_11` 툴팁 크기: XML에서는 `<Sheet … maxwidth="300" maxheight="300">`로
  **기본값이 이미 박혀 있다.** UI 경로는 미관찰(`?`) — 도구 설명 편집창의 해당 줄을
  직접 고치면 되는 것으로 보이나 확인 안 됨
- `filter-group` 속성 규칙은 **여전히 미상**. 데이터 원본 필터엔 `'2'`가 붙고
  워크시트 필터 5건엔 하나도 안 붙었다
